# LUMIE SKIN LP

架空のスキンケアブランド「LUMIE SKIN」の自主制作ポートフォリオです。実際の商品販売・決済・個人情報の収集は行いません。

公開URL: https://bon214.github.io/lumie-skin-lp/

## ファイル

- `index.html`: 公開用トップページ（日本語・ページタイトル・共有用メタ情報を追加）
- `LUMIE SKIN LP.dc.html`: 元の制作ファイル
- `support.js`: HTMLテンプレートの描画と動作に必要なランタイム
- `lumie-logo.svg`: 表示用ロゴ
- `uploads/LUMIE SKIN logo.svg`: 元のロゴ素材
- `_config.yml` / `_layouts/release.html`: 公開時に更新番号を自動で挿入する設定

## 公開と更新

GitHub Pages の「Deploy from a branch」で `main` ブランチのルート `/` を公開します。公開ページの修正は `index.html` に反映してください。`main` に変更をコミットすると、GitHub Pages標準のJekyll処理を経て自動で再公開されます。

公開リポジトリと標準のGitHub Pagesを使用します。有料プラン・独自ドメイン・有料サービスは使用していません。

## 外部依存

React 18.3.1、ReactDOM 18.3.1、Babel 7.29.0 は既存の `support.js` により unpkg から読み込みます。書体はGoogle Fontsを使用します。外部CDNへのアクセスが必要です。

## 確認する動作

スマートフォン用メニュー、ページ内リンク、FAQの開閉、購入デモの表示・終了、画面幅に応じたレイアウト。

## 商品画像

`assets/images/` にAI生成の商品写真・日常シーン・美容液の接写を保存しています。架空商品のイメージであり、実物の撮影写真ではありません。生成条件は `assets/IMAGE-PROMPTS.md` を参照してください。

## アニメーション

`motion.js` と `motion.css` で、導入テキストの段階表示、スクロール時のフェード、写真のマスク展開と微細なズーム・光の変化、FAQ・メニュー・購入デモの表示アニメーションを実装しています。新しい外部ライブラリや有料サービスは使用しません。

端末の `prefers-reduced-motion` 設定にリアルタイムで対応し、制作ファイルの `animate: false` でも停止できます。停止時とJavaScriptの不具合時にも本文を隠さない設計です。

検証: PC・390px幅での表示、FAQとモバイルメニュー、設定変更時の停止・再開と後処理を確認。

## 開いたタブへの更新反映（2026-09-08）

- GitHub Pages標準の `site.github.build_revision` をHTMLと `site-version.json` に自動挿入します。誰が更新しても、文章・CSS・JS・画像などの変更がmainに公開されれば検知できます。更新番号の手動変更や外部API・有料サービスは不要です。
- 表示中は60秒ごと、タブへの復帰・通信復帰・戻る操作でも確認。更新先HTMLと主要な同一サイトのCSS/JSの取得に成功した場合のみ案内を表示し、6秒間操作が落ち着いたら再読み込みします。メニュー・ダイアログ・入力欄の操作中は待機し、「今すぐ更新」でも反映できます。
- すべての既存ローカルCSS/JS/画像のURLに公開番号を付け、古いブラウザキャッシュの再利用を抑制します。今後素材を追加する場合もURL末尾に `?v=__LUMIE_RELEASE__` を付けてください。CSS内で新たに画像を参照する場合は画像名を変更してください。
- 現在のURLのパラメータ・アンカーを保ち、可能な場合はスクロール位置も復元。同じ公開番号の連続更新を抑制し、通信エラー・未公開・不正な応答では現在のページを維持します。
- 導入前から開いているタブは初回手動更新が必要。休止中・通信不能時の即時反映、外部CDN障害やコード自体の不具合の完全防止はできません。販売・入力フォームを今後追加するときは、入力内容の保存と更新待機の設計も見直してください。

### 編集とプレビュー

HTML冒頭のfront matter、`{% raw %}` / `{% endraw %}`、`__LUMIE_RELEASE__` は公開処理に必要です。raw内の `{{ ... }}` は既存描画機構の式として保護しています。`.nojekyll` は復活させないでください。公開元設定は今まで通り「Deploy from a branch / main / root」です。

`python3 scripts/preview.py` で公開時の置換を再現したプレビューを起動します（localhost:8765）。ファイル変更ごとにプレビュー用更新番号も変わるため、タブを開いたままの更新動作を確認できます。本番のJekyll自体の動作確認はGitHub Pagesの公開結果で行います。

`node --test tests/site-update.test.cjs` で更新検知・操作待機・通信失敗・未反映ページ・連続リロード防止を確認できます。
